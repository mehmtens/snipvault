SnipVault API v1

Developer reference

Small API.
Clear contracts.

Create, protect, retrieve, update and expire code pastes. Browser sessions use HttpOnly cookies and CSRF protection; API clients may use Bearer tokens.

Download OpenAPI 3.1 specification
GET/health

Service health status.

POST/register · /login · /logout

Secure account and session lifecycle.

POST/pastes

Create an anonymous or owned paste.

GET/pastes/{slug} · /raw/{slug}

Read a visible paste as JSON or plain text.

PUT/pastes/{slug}

Update a paste owned by the authenticated user.

DELETE/pastes/{slug}

Delete a paste owned by the authenticated user.

GET/me/pastes

List the current user's active pastes.
